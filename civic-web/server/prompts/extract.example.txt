Template only. This file contains no part of the real prompt.

Copy it to extract.txt and paste the operator's claim-extraction prompt in place of this text, or
point CIVIC_PROMPT_EXTRACT_FILE at a file outside this repository, or set CIVIC_PROMPT_EXTRACT.
extract.txt is gitignored and must never be committed.

Contract: the whole file is sent to the API byte for byte. If its last line is written entirely
in square brackets, the submitted source is put in place of that line and the whole is sent as
the only message. Otherwise the file is sent as the `instructions` field, with the source as the
only message. Nothing else is added to it or removed from it.
The reply is expected to be a numbered list; each numbered entry is one claim. An entry may be
written as labelled lines: the text under a `Claim:` label is what is tested, and any further
labelled lines (who said it and when, what the source does not say) are shown beside it.
